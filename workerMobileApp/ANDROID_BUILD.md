# Building the Worker App on Android

This app uses **bare React Native 0.85.3** (no Expo). The native `android/`
project is generated by the React Native CLI and pinned to:

| Tool | Version |
|---|---|
| compileSdk / targetSdk | 36 |
| minSdk | 24 |
| buildTools | 36.0.0 |
| NDK | 27.1.12297006 |
| Kotlin | 2.1.20 |
| Gradle wrapper | 9.3.1 |
| Hermes | enabled |
| New Architecture | enabled |
| Android Gradle Plugin | (resolved by gradle wrapper) |
| Package / applicationId | `com.workerapp` |
| App label | `SafetyCore HSE` |
| Main component | `WorkerApp` |

## Quick start (Windows)

```bat
cd workerMobileApp
run-android.bat
```

`run-android.bat` does all of this for you:
1. Sets `JAVA_HOME` to Android Studio's bundled JDK
2. Creates the `Z:` short-path drive to dodge Windows long-path issues
3. Writes `android/local.properties` with `sdk.dir` if missing
4. Boots the `Pixel_6a` AVD if no emulator is running
5. Runs `gradlew.bat app:installDebug -PreactNativeDevServerPort=8081`
6. Forwards Metro port and launches `com.workerapp`

## Common build errors & fixes

### "SDK location not found"
- `run-android.bat` now creates `android/local.properties` automatically. If
  you run gradle manually, write `sdk.dir=C:/Users/<you>/AppData/Local/Android/Sdk`
  into that file.

### "Could not determine java version from 'X'."
- Your `JAVA_HOME` points at a too-old or non-Java binary. Use the JDK
  bundled with Android Studio at `C:\Program Files\Android\Android Studio\jbr`,
  or install JDK 17 from https://adoptium.net.

### "Minimum supported Gradle version is X.X"
- The project ships `gradle/wrapper/gradle-wrapper.properties` pinned to
  Gradle 9.3.1. Do not override the wrapper version.

### "Android Gradle plugin requires Java 17 / 21"
- AGP 8.x requires JDK 17+. Use the bundled `jbr` (which is JDK 21 on recent
  Android Studio).

### "NDK at .../27.1.12297006 did not have a source.properties file"
- Open Android Studio > SDK Manager > SDK Tools > check "Show Package Details"
  > install NDK (Side by side) 27.1.12297006.

### "Could not resolve com.facebook.react:react-android"
- Run `npm install` from the `workerMobileApp` directory so
  `node_modules/@react-native/gradle-plugin` is present. The settings.gradle
  uses `includeBuild("../node_modules/@react-native/gradle-plugin")` which
  needs that directory to exist.

### Metro bundler errors
- The app is launched in debug mode and fetches JS from Metro on port 8081.
  Run `npm start` in a second terminal before/while installing the app.
- `run-android.bat` already does `adb reverse tcp:8081 tcp:8081` so the
  emulator can reach Metro on the host.

### Build is slow / OOM
- The default `org.gradle.jvmargs=-Xmx2048m` is in `gradle.properties`.
  Bump to `-Xmx4096m` if you have RAM headroom.

### First build wants to download a LOT
- Gradle 9.3.1 distribution, AGP, Kotlin, NDK toolchain, all the React Native
  transitive AARs, and Hermes prebuilts. Expect 2-5 GB of downloads and
  5-15 minutes on a clean machine. Subsequent builds are fast.

### `Class file has wrong version X.0, should be 65.0`
- Your Gradle is too old to read the JDK 21 class files. The wrapper pins
  Gradle 9.3.1 which supports JDK 21 — make sure you are invoking
  `gradlew.bat`, not a system `gradle`.

## iOS

You need a Mac with Xcode 16+ and CocoaPods installed. From `workerMobileApp/`:

```bash
cd ios && pod install && cd ..
npx react-native run-ios
```

Note: the boilerplate iOS bundle id is `org.reactjs.native.example.WorkerApp`
and has not been changed — you may want to rename it to `com.workerapp` for
parity with Android before App Store submission.
